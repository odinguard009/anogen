# Consistency settings — Arc 1 (chapters 1–50)

Owner order, 28 Nov 2026. This is a **setting for future rewrite work**. Chapters are not edited by this file.

## 1. Why this file exists

A scan of chapters 1–50 found the same thing called by two names, and special words used before they are explained. The most serious case: **Lance Nine** was read as a numbered spear instead of a group of five students.

## 2. Canonical names — use only these

| Thing | Canonical word | Meaning, said plainly at first use | Do not use |
|---|---|---|---|
| Student unit | **group** (official name: Lance Nine) | first use only: "Lance Nine, a group of five students"; after that "the group" | numbered spear, "lance" in narration |
| Other unit | **group** (official name: Lance One) | "the other group" after first use | numbered spear |
| Job name | **[Black Lancer]** | "a knight with a dark lance" — this is a job, not a group | using it to mean a team |
| Black knights | **Thirteenth Vigil** | "knights in black armor, nobody knows their names" | "Black Thirteen" except as a rumor, and then explain it |
| Grey foot soldier | **Husk** | "a dead body moved by grey magic" | Hushborn, Veil |

| Taken person | **Veil** | "a person with a grey thing inside, wearing his face" | Husk, Hushborn |

- **Eden Wren** — the name everyone uses. True name **Eden Aster Argentine** is a secret until ch 160. Never use "Argentine" in narration before then.

- **Ysolde Lisle**, **Tesfane Okoru**, **Gorrath**, **Vesk**, **Mirelle**.

## 4. Things that must not be mixed

- **Handkerchief** — small white cloth with a silver feather. Given in ch 1, washed and folded by ch 26. Eden keeps it.
- **Scarf** — grey wool, Lysette's; loaned in ch 33, worn all winter. A different object.
- **Rank eight** — write the number as a word ("rank eight"), never "rank 8" in narration.
- **Corentin Hollen** — Lysette's brother, executed in PR 110 by the Vigil. She does **not** know who did it until ch 140.
- **Liora** — Eden's mother, dead before the story. The Tailor sends regards in ch 50; the full truth waits until ch 400.
- **Ashen Crowns**: **Cinder** = new recruit, **Ember** = soldier, **Crown** = grafted leader. Use only these three.

## 5. Detected inconsistencies to fix in the rewrite

1. "Black Thirteen" (ch 21) vs "Thirteenth Vigil" (ch 3, 13, 20, 36, 37) — one name, two labels. Keep "Thirteenth Vigil"; explain "Black Thirteen" as a rumor if used.
2. "Hushborn" (ch 31, 46) vs "Husk" (9 chapters) — no plain difference given. Add a one-sentence definition at first use of each.
3. **Lance Nine / Lance One** — no plain explanation at first use. In the rewrite, say "the group" in narration; use "Lance Nine" only once as the official name, with "a group of five students" on the same line. Never use "lance" by itself to mean a team.
4. "veinline" and "vein-steel" each appear once in ch 28 without explanation. Add a plain sentence there.
5. "Halvard Strent" and "Strent" are mixed; give the full name at first use in each chapter.
6. ch 27 says the summons came "on Saturday morning" although that chapter covers Mon–Fri 14–18 Dec. Check against `story/bible/calendar.md` when rewriting ch 27.
7. "handkerchief" and "scarf" both appear; confirm they are never treated as one object.
8. First-use labels for **[Tavu]**, **[Ithe]**, **[Wyl]**, **[Osk]**, **[Thessa]**, **[Grask]**, **[Citation]**, **[Lampwick]** exist in `first-use.md`; keep the descriptions and the costs when rewriting.

## 6. Rule for all future chapters

- One thing = one name.
- Explain the name at first use in one plain sentence.
- Check `story/bible/state.md`, `calendar.md`, `characters.md`, `first-use.md` and this file before drafting any chapter.
- If a new name is needed, add it to this file first, then use it in the chapter.
